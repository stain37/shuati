刷题站 · 使用说明

这是一个纯静态的刷题网站：选择题目当场判分、错题自动进错题本、能模拟考、能用 AI 写解析，
还能让 AI 先翻自带的资料库再回答。不用安装、不用联网也能刷题。

  这份说明是给「拿到这个文件夹的人」看的。原作者的其他文档（README.md、AI知识库说明.md、
  更新说明.md）都还在，想深挖再看。

  这一份是「纯净版」：原作者自己的 API 配置（AI配置.js）已整套去掉 —— 站点目录里没有
  配置文件，页面上也没有任何预置的接口地址 / 模型 / Key，包里没有密钥。AI 配置只有一条路：
  在页面上填一次（只存在本机浏览器里），见第三节。想加题就用网页上的「导入题库」，
  或按第六节导入数据备份。


■ 一、先打开它（两分钟）

方式 1（最省事）：双击 index.html —— Chrome / Edge 都行，直接就能刷题。
　· 作答记录存在这台电脑的浏览器里（换浏览器、清缓存会丢，重要数据请导出备份，见第六节）。

方式 2（推荐）：双击 本地服务器.bat —— 会用 http://localhost:5173/ 打开。
　· 好处：可以「安装到桌面/主屏」离线使用、自己导入的知识库能存进 IndexedDB（容量大得多）、
　　中文输入法更顺、连本机 Ollama 也更稳。
　· 要电脑装了 Python（python.org 下载时记得勾 "Add python.exe to PATH"）。
　· 黑窗口别关，关掉就等于关掉服务器。

　· 没装 Python 也没关系：现在这个 .bat 会自动改成直接打开 index.html，功能一样不少。

方式 3（手机也能刷）：双击 手机访问.bat —— 手机连同一个 Wi-Fi，用浏览器打开窗口里显示的地址
（形如 http://192.168.x.x:8080/）就能刷题，和你电脑上看到的是同一套题库。
　· 不用上传、不用注册，纯局域网；电脑要开着，黑窗口别关。
　· 这种 http 地址在手机浏览器里不能「装成 App」、不能离线，其它功能（资料库、AI、错题本）都正常。
　· 想手机上长期用、能离线、有图标 → 看第五节。

方式 4（电脑上像软件一样）：双击 像App一样打开.bat —— 用 Edge / Chrome 开一个没有地址栏、
没有标签页的窗口，看起来就是个软件；找不到就用默认浏览器打开。


■ 操作小抄（顺手一下就会）

首页从上到下：统计看板 → 继续刷题（上次刷到哪一题，点一下接着刷）→ 一排常用按钮 → 目录导航 + 我的题库
→ 数据备份。点题库名、卡片或「开始」进答题页。

分类目录（首页「我的题库」那一块）：
　· 新建目录：点「＋ 新建目录」，目录里还能再套子目录；点目录名进出，右边的箭头折叠或展开。
　· 把题库放进去：直接把卡片拖进目录；手机上不方便拖，就在卡片上点「移到…」选一个目录。目录之间也能互相拖。
　· 目录名后面写着「几套题库」；顶上的「目录导航」是一排按钮，点一下直接跳到那个目录。
　· 搜索框写着「搜索目录 / 题库名」：按目录名也能搜，命中时会把该目录下所有层级的题库一起列出来。
　· 目录只是「归属」，不会动题库本身；删目录只把里面的东西挪到上一级，题库一道题都不会少。

答题页：
　· 选选项：鼠标点，或直接敲字母 A–H / 数字 1–8；多选先把选项都选上，再按 Enter 提交。
　· 翻题：← →；底部中间的按钮显示「第几题 / 共几题」，点它是答题卡。
　· 答题卡里能筛「全部 / 做错 / 没做」，点题号直接跳；题号右上角黄点＝你自己标的记号。
　· S 收藏当前题，K 开答题卡（选项字母被 A–H 占着，所以收藏和答题卡特意用 S / K），? 看全部快捷键，Esc 关掉弹窗。
　· 判完分会自动把解析滚到眼前（不想自动跳下一题，去设置里关掉「答对自动下一题」）。

搜索与错题本：
　· 搜索页按 / 直接跳到搜索框；搜索框吸在顶部，翻长列表不用回头。
　· 错题本 / 收藏页的「勾选、批量、套卷、导出」收在「批量操作与导出」折叠条里，点开才展开
　（折叠条上写着已经勾了几题）。

外观与手机：
　· 顶栏的 ◐ 一键切换：跟随系统 → 浅色 → 深色（设置里也能选）；设置里还能调字号。
　· 手机上顶栏分成两行：第一行标题 + 设置/答题卡，第二行「错题 / 收藏 / 搜索 / AI」，都点得到。
　· 底部导航贴着屏幕底部也不会被 iPhone 的横条挡住。


■ 二、配 AI（想用「AI 解析」才需要，不配也能刷题）

配法只有一条（纯净版没有任何预置配置文件，只能手填）：

· ① 在网页里填一次（最简单，1 分钟）
1. 打开站点 → 点「AI 与知识库」（或题目下方的「AI 解析」）
2. ① AI 服务：下拉选一个，常用的有
　　　· DeepSeek 云端 API　　接口地址 https://api.deepseek.com/v1　模型 deepseek-flash 或 deepseek-v4-pro
　　　· Kimi / Moonshot　　 https://api.moonshot.cn/v1　　　　　　模型 moonshot-v1-8k
　　　· 本地 Ollama（免费、离线）http://127.0.0.1:11434/v1　　　模型 qwen2.5:7b，API Key 留空
　　　· 本地 LM Studio　　　 http://127.0.0.1:1234/v1　　　　　　模型填它显示的模型名
　　　· 自定义　　　　　　　任何「OpenAI 兼容」的接口都行，地址一般以 /v1 结尾
3. 把 API Key 粘进「API Key」框（本地模型不用填）
4. 模型：点「模型」框会列出这个服务的常用名字（选了 DeepSeek 就有 deepseek-flash / deepseek-v4-pro
　 可选）；想拉服务端真实可用的全部名字，点旁边的「拉取模型列表」（要先填好 Key）。
5. 点「测试连接」→ 显示 OK 就能用了。
配置只存在这台电脑的浏览器里，不会上传到任何地方。
（注意：同一个浏览器里所有 file:// 页面共用一份存储，所以在同一台电脑上打开别人分享的副本时，
　可能看到你自己先前填过的配置 —— 那是本机浏览器里的，不是文件里的。点①里的「清空本机配置」
　可一键清掉；换电脑或开无痕窗口打开就是空的。见第六节 FAQ。）

· ② 这一版没有「预置配置文件」这条路

纯净版把原来的 AI配置.js 整套机制去掉了：站点目录里不放配置文件，网页也不会去读它，
所以打开时①里是空白的（服务 = 自定义，接口地址 / 模型 / Key 都是空的）。
想给多台电脑用同一个配置，就在每台电脑上各填一次（10 秒），或者把本机浏览器的数据
搬过去。原来的 AI配置.示例.js、从Chatbox导入.bat、chatbox-import.py 都不在这个文件夹里了。

· 完全免费的离线方案
装 Ollama（ollama.com）→ 命令行执行 `ollama pull qwen2.5:7b` →
再设一个环境变量 OLLAMA_ORIGINS=* （否则网页连不上它，详见 AI知识库说明.md）。
■ AI 写出来长什么样，由你说了算
· 默认不套任何固定格式：你在提问框写什么，它就写什么。
· 想要每道题固定输出「答案 / 为什么 / 其它选项 / 易错点」，在配置页勾上「套用……模板」。
· 想长期固定要求（比如「用大一水平讲」「只讲错的那个选项」），写在「额外要求」里，会一直生效
　（和模板是叠加的，不是替换）。


■ 三、自带的资料库（315 万字，已经打包在文件夹里）

资料库  ｜  文件数  ｜  正文字数
Chatbox·西综  ｜  157 篇  ｜  约 157 万字
Chatbox·内科  ｜  75 篇  ｜  约 81 万字
Chatbox·生化  ｜  34 篇  ｜  约 28 万字
Chatbox·生理  ｜  4 篇  ｜  约 24 万字
Chatbox·外科  ｜  43 篇  ｜  约 19 万字
Chatbox·病理  ｜  1 篇  ｜  约 5 万字

· 它们在 知识库.js 这个文件里（网站打开时自动挂载），在「AI 与知识库」页就能看到。
· 做题时点「AI 解析」，它会先从这些资料里检索出最相关的几段，再让模型照着写解析。
· 想让 AI 只用其中几个库：AI 面板顶部那排标签，点一下亮 / 再点灭，可以多选；
　第一个「总库 · 全部」= 一键全选；一个都不选就纯靠模型自己的知识回答。
· 检索几段合适：默认 4 段够用（面板上有实时提示，调大「检索片段数」记得把「资料上限」也调大）。

· 加自己的资料
1. 把 .pdf / .docx / .txt / .md 丢进站点目录的 资料\ 文件夹
2. 双击 转知识库.bat（需要 Python；读 PDF 还要先 `pip install pypdf`）
3. 回到网页按 Ctrl+F5 刷新 —— 新资料库就出现了

· 关于容量
文件库（知识库.js）不占浏览器空间，跟着文件夹走就行。
自己在②里粘贴/导入的资料才会存进浏览器：用「本地服务器.bat」打开时存 IndexedDB（容量大），
双击 index.html（file://）时只能退回 localStorage（约 5 MB），大资料请走 资料\ + 转知识库.bat 这条路。


■ 四、搬走你的记录（换电脑/重装前必看）

作答记录、错题本、收藏、自定义解析、自己导入的题库都存在这台电脑的浏览器里。
搬家办法：首页拉到最下面 →「数据备份」→「导出全部数据」得到一个 .json 文件；
在新电脑的站点里点「导入数据（恢复）」选这个文件即可。
备份里含作答、错题、收藏、解析、自己导入的题库和知识库正文；
知识库.js 里的文件库不打包（它本身就在文件夹里，跟着走就行）。

更省事的办法：让数据自己写进本机文件。首页「数据备份」卡里点「选择文件」，挑一个 .json 作为存档
（建议叫「刷题站-题库备份.json」）；以后每次改动都会自动写进这个文件，不用记着点导出
（Chrome / Edge 支持；同排还有「立即写一次 / 打开别的文件 / 断开」，边上会显示「上次写入 时间」）。
换电脑时把这个 .json 拷过去，用「打开题库文件」或「导入数据（恢复）」读回来即可。


■ 五、做成手机 App / 放到网上

三条路，按需要挑一条：

① 只在同一个 Wi-Fi 里用（最快，不上传任何东西）
双击 手机访问.bat → 手机浏览器打开窗口里显示的地址（形如 http://192.168.x.x:8080/）。
　· 电脑要开着、黑窗口别关；手机和电脑连同一个 Wi-Fi。
　· 资料库、AI 解析、错题本都能用；但 http 不是安全环境，不能装成 App、不能离线。

② 放到网上，手机「安装」成 App（想长期用就这条）
把整个文件夹上传到任意静态托管即可（无需构建、无后端）：Cloudflare Pages、GitHub Pages、
Netlify、Vercel，网页上拖拽上传就行。然后手机浏览器打开那个网址，会提示
「添加到主屏幕 / 安装应用」—— 装完就是 App 的样子：有自己的图标、全屏无地址栏、
断网也能刷题（自带的资料库也在离线缓存里，见下）。
　· 具体步骤（Cloudflare Pages / Netlify Drop / GitHub Pages 三条路、手机安装、数据搬家、不传资料库的瘦身版）另见 上传步骤.md。
　· 手机上的 AI 解析：云端 API（DeepSeek / Kimi）没问题；电脑上的 Ollama 手机访问不到。
　· 上传前想清楚一件事：知识库.js 是资料正文（版权自己把握）。这一版没有 AI配置.js，站点文件里不含任何 Key。

③ 想要真的 .apk 安装包
把②的网址丢进 https://www.pwabuilder.com/ ，它会在云端打好 Android 包给你下载
（不用装 Android Studio、不用 JDK）。本站已经具备它要的三样：https、manifest.json、service worker。

手机 App 里还能用自带资料库吗？
能，而且离线也能搜。知识库.js 就是站点文件的一部分，装成 App 后它同样在这份离线缓存里，
检索段落、AI 照资料写解析、知识库标签勾选，全都和电脑上一模一样；
只有①那种局域网方式才是每次找电脑要数据，电脑一关就没了。


■ 六、常见问题

Q：打开是白屏 / 排版乱了？
A：按一次 Ctrl + F5 强制刷新。还不行就换个浏览器（Edge / Chrome），或确认文件夹是完整解压出来的。

Q：双击 .bat 黑窗口一闪就没了？
A：说明没装 Python。直接用方式 1 双击 index.html 就行；或者装 Python 时勾上 Add to PATH。

Q：「AI 解析」报错连不上？
A：①先用「测试连接」看配置对不对；②本地模型要确认服务在跑、并设了 OLLAMA_ORIGINS=*；
③云端要确认 Key 有余额、模型名没写错（DeepSeek 现在只有 deepseek-flash 和 deepseek-v4-pro；老的 deepseek-chat / deepseek-reasoner 官方已下线）。

Q：我一打开副本，AI 配置里怎么还显示我自己填过的 Key？
A：站点文件里没有你的 Key，这一份连 AI配置.js 这一套都没有，网页打开时是空白的。你看到的是这台电脑浏览器里
　存过的那份配置：同一个浏览器里，所有用 file:// 打开的页面共用一份存储，所以会把你自己在别的
　刷题站页面填过的配置带过来。核对办法：① 点配置页的「清空本机配置」按钮，当场就没了；
　② 换一台电脑或开无痕窗口打开，是空的；③ 在文件夹里搜 "sk-"，这一份搜不到。

Q：可以删掉哪些文件？
A：以下都能删，删了站点照常跑：
　· AI知识库说明.md（原作者文档，讲的是 Chatbox 导入那套，本副本没有这些工具）
　· make-kb.py / 转知识库.bat / 资料\（不想自己加资料时）
　· 更新说明.md（原作者的开发记录）、usage-*.txt
　· 知识库.js（不要自带资料库时，删了 AI 就只靠模型自己回答）
　不能删：index.html、app.js、collection.js、exam.js、kb.js、ai.js、style.css、sw.js、manifest.json、icons/、banks/

Q：能放到网上给别人用吗？
A：可以，整个文件夹丢 GitHub Pages / Vercel / Netlify 或任意静态空间即可（无需构建、无后端）。
　但两点注意：① 知识库.js 是资料正文，公开前先想清楚版权；② 每个访客的记录存在各自浏览器里，不互通。

Q：手机上能用吗？
A：能。想立刻试：双击 手机访问.bat，手机连同一 Wi-Fi 打开它显示的地址。
　想长期用、能离线、有图标：按第五节②放到网上，再用手机「安装应用 / 添加到主屏幕」。
