刷题站 · 纯净版说明
（这一份是在「刷题站-在线版」基础上做的副本，差别只有一处：整套「API 初始配置」被删掉了）

一、和原版有什么不一样
1. 不再有任何预置的 API 配置：
   · 站点目录里没有 AI配置.js，也没有 AI配置.示例.js；
   · 网页打开时不会去读任何配置文件（原来那个「重新读取 AI配置.js」按钮已经删掉）；
   · 「AI 服务」默认显示「自定义」，接口地址 / 模型 / API Key 全是空的，第一次打开要自己填；
   · 包里不含任何密钥（在文件夹里搜 "sk-" 搜不到）。
2. 跟着配置一起删掉的文件：
   AI配置.示例.js、从Chatbox导入.bat、chatbox-import.py、usage-chatbox.txt
3. 其它功能一个不少：题库 / 目录分类 / 错题本 / 收藏 / 模考 / 批量导入题库文件夹 /
   自带的 6 个知识库（知识库.js）/ 转知识库.bat / 手机与离线（PWA）都照常能用。
   注意：「服务」下拉里的 DeepSeek / Kimi / Ollama 只是模板，选了才会带出示例地址，
   不选就一直是空白 —— 那不叫预置配置。

二、AI 怎么写配置
1. 打开站点（推荐双击「本地服务器.bat」，或直接双击 index.html）；
2. 顶栏点「AI」，进「AI 与知识库」页；
3. 在 ① 里：选一个服务（例如 DeepSeek）→ 填接口地址 → 填模型名 → 粘上自己的 API Key；
4. 点「测试连接」，出现 OK 就能用「AI 解析」了。
   · 填好的东西存在这台电脑的浏览器里（localStorage 键名 qbank.ai.v1），换电脑 / 清缓存要重填；
   · 站点文件里没有你的 Key，把这个文件夹发给别人也不会泄露。注意同一个浏览器里所有
     file:// 页面共用一份存储，所以可能看到你自己之前填过的值 —— 点「清空本机配置」即清掉。

五、改代码后的固定动作
改了任何 .js / .css，都要把 index.html 里的 ?v= 版本号抬一次、并把 sw.js 的 VERSION 加一，
否则浏览器（Service Worker 缓存）可能还在跑旧文件。
本副本的版本：index.html 用 ?v=20261014p，sw.js 用 shuati-v18-pure1。
