这个文件夹用来放题库文件：一个 .js 文件 = 一个题库。

本包（在线版）里是空的 —— 原作者的内置模考卷已经移除。
要加自己的题库，两种办法：

1）网页里加（不用碰文件，最省事）
   打开网站 → 首页「＋ 导入 / 新建题库」→ 粘贴题目文本或导入 JSON。
   这样加的题库存在浏览器里；换浏览器 / 清缓存会丢，记得用「导出全部数据」备份。

2）文件里加（要会改文件）
   把题库 .js 放进本文件夹，再在 index.html 里加一行：
       <script src="banks/你的题库.js"></script>
   题库文件里调用站点提供的注册函数（index.html:21 定义，app.js 的 baseBanks() 读取）：
       registerBank({ id: 'my-bank', title: '我的题库', questions: [ { id: 1, type: 'A', stem: '题干', options: ['A选项','B选项'], answer: 'A' } ] });
   answer 一个字母 = 单选，多个字母 = 多选。完整格式见 README.md「加自己的题库」。

提示：没有题库文件也能用 —— 首页在没有题库时会显示「还没有题库」和导入按钮。
